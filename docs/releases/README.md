# Release candidates

Each `0.x.y/` directory holds the **verification evidence** for one
release candidate, generated by
`python -m organvm_engine.ci.release_evidence` from the exact checkout
named in its `provenance.json`:

- `sbom.json` — CycloneDX 1.6 inventory of the resolved dependency set.
- `sha256sums.txt` — hashes of the wheel, sdist and SBOM.
- `provenance.json` — builder, checkout SHA, tool versions, the
  exclusion list applied, and the clean-room checks that passed.
- `rollback.json` — the tested-rollback receipt, generated by
  `python -m organvm_engine.ci.release_rollback`.

Status is in `provenance.json`: `"candidate"` means verified, not
shipped. A version is only released when a `v*` tag exists and a
GitHub release carries the artifacts — see `.github/workflows/release.yml`
(organvm-engine #195). The evidence is generated at release time by
that workflow; the copies here are the candidate receipts for this
version, kept so a clean consumer can check the artifact without
re-running the build.
